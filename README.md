# huawei-cloud-certified-developer-ai
this repositries contain 12 weeks learning material containing  python, machine_learninig, deep_learning, hugging_face etc.

Week	Topic	Learning Focus
Week 01	Python Fundamentals	Python syntax, variables, data types, loops, functions, OOP
Week 02	Python for Data Science	NumPy, Pandas, Matplotlib, data manipulation
Week 03	Mathematics for AI	Linear algebra, statistics, probability, calculus fundamentals
Week 04	Machine Learning Fundamentals	Supervised learning, unsupervised learning, model training
Week 05	Machine Learning Algorithms	Regression, classification, clustering, decision trees
Week 06	ML Model Evaluation	Evaluation metrics, validation, feature engineering, overfitting
Week 07	Deep Learning Fundamentals	Neural networks, perceptrons, activation functions, backpropagation
Week 08	Deep Learning Frameworks	TensorFlow/PyTorch, model building and training
Week 09	Natural Language Processing	Text preprocessing, tokenization, embeddings, NLP tasks
Week 10	Hugging Face & Transformers	Transformers, pretrained models, tokenizers, pipelines
Week 11	Generative AI & LLMs	Large Language Models, prompt engineering, model inference
Week 12	Huawei Cloud AI & Capstone	Cloud AI services, deployment concepts, practical AI project
